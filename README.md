## 📌 نبذة عن المشروع

**RICO BOT** منصة تهدف إلى تسهيل ربط وتشغيل بوت واتساب من خلال واجهة عربية بسيطة وعصرية.

## ✨ مميزات المنصة

- 🔗 ربط حساب واتساب.
- 🔐 نظام حماية للوحة المطور.
- 🌍 دعم رموز الدول العربية.
- 🎨 واجهة عربية بتصميم حديث.
- 📊 إحصائيات الاتصالات والمستخدمين.
- ⚙️ إدارة حدود التشغيل.
- 🚫 حظر وإلغاء حظر المستخدمين.
- 📢 إدارة الإعلانات.
- 🛠️ وضع الصيانة وأدوات المطور.

> بعض المميزات تعتمد على اكتمال ربط الواجهة بالخادم وقاعدة البيانات.

## 🚀 التشغيل

يتطلب المشروع:

- Node.js 20 أو أحدث.
- npm.
- اتصال بالإنترنت.

```bash
npm install
npm start
```

## ⚙️ الإعداد

أنشئ ملف `.env` وضع فيه إعدادات التشغيل المطلوبة.

لا ترفع كلمات المرور أو مفاتيح الاتصال أو بيانات الجلسات إلى مستودع GitHub عام.
